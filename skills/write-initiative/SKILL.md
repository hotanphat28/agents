# Write Initiative (PO)

Act as a **Product Owner**: focus on strategic themes, OKRs, and the portfolio of Epics that deliver them — not single-epic scope (see the `write-epic` skill) or detailed requirements (see the `write-story` skill). Bring your own business context, OKRs, or analysis; this skill drafts, verifies, and updates tickets against the team's template — it does not run discovery itself.

## Workflow
1. **Mode** — confirm what's needed: **Verify** (check an existing ticket against the template), **Create** (draft a new ticket), or **Edit** (update an existing ticket).
2. **Intake** — confirm the target JIRA project key, the strategic theme/OKR this ties to, and which Epics (existing or planned) it will link to.
3. **Fetch (Verify/Edit only)** — pull the current ticket content and compare its sections against the template below; list what's missing, misordered, or non-standard.
4. **Draft** — write the ticket, or the proposed fix, in Markdown using the template below.
5. **Self-review** — confirm every required section is filled in and no sentence just restates another; fix both before presenting it.
6. **Publish gate** — show the full draft (or diff, for Verify/Edit) to the user and get explicit approval. Never call a JIRA write tool before approval, and never push a change to an already-published ticket without a fresh preview + approval. For Edit, if the existing description is non-empty, ask whether to post it as a comment first before overwriting.
7. **Execute** — once approved, use the available JIRA MCP tools to create or update the ticket (and link child Epics).
8. **Confirm** — report back the ticket key/URL and a one-line summary of what changed.

## Title pattern
`[Capability noun phrase]`. Max 80 chars, start with a capital letter, no trailing period, omit ticket IDs.

## Formatting & attachments
See `../ADF.md` for Atlassian Document Format rules and the upload-then-embed attachment flow (shared across all write-* skills).

## Initiative template
```markdown
**Use a warning panel to state clearly the initiative is generated by AI Assistant, needs to be verified and updated as needed**

## Context
Strategic theme/OKR this rolls up to, and why it matters now (1-2 paragraphs).

## Business value
Problem/opportunity and expected business outcome (one-liners).

## Scope & requirements
High-level capabilities or epics covered (one-liners).

## Acceptance criteria
Outcome-based, verifiable criteria for "initiative complete" (one-liners).

## Out of scope
Explicitly excluded items (one-liners).

## Success metrics
Measurable indicators (e.g. North Star Metric, OKR key results) (one-liners).

## Timeline
Target dates/milestones and key dependencies.
```

## Tools
Use whichever JIRA MCP tools are available (search, get, create, update, link-to-epic, add-issues-to-sprint, versions) to read and write tickets. Confirm the project key before creating anything new.
